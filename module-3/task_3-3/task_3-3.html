1. What is the difference between invoking and creating a function?

    2. Creating a function means defining what it does, while invoking a function means calling it to execute its code.

  2. Explain the syntax regarding semicolons and code blocks.

    3. Semicolons are used to terminate statements in JavaScript, while code blocks are defined by curly braces {}.

  3. What happens when we try to store values from a function when it doesn't return any?

    4. When we try to store values from a function that doesn't return anything, the variable will be assigned the value undefined.

  4. How do we separate parameters from each other when creating a function?

    5. Parameters are separated by commas when creating a function.

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. Parameter names in the function definition are matched with the arguments provided during the function call based on their position.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. A parameter is undefined when a function call is missing a parameter because no value is passed for that specific parameter.

  7. Explain what happens when we use recursive functions.

    8. Recursion is when a function calls itself to solve a smaller version of the code.
