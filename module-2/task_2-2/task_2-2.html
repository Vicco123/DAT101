1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. You should use constants for fixed values that never change, and variables for data that needs to update while the program runs. No, they cannot all be constants because most programs rely on changing data to function.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses override the standard order of operations by forcing the calculation inside them to happen first.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We can use the Strict Equality (==) comparison operator.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. They return true or false, and we can check it by testing the statement with comparision operators.

  6. How does the Math.random() function work, and what can it be used for?

    7. It returns a random decimal number between 0 and 1.

  7. What is modulus (%), and when do we need this operator in mathematical operations?
